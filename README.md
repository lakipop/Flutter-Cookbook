# 📱 ICT4153 — Flutter Cookbook
**Mobile Application Development | Dept of ICT, Faculty of Technology, University of Ruhuna**

A collection of Flutter practicals, mini-apps, and in-class projects built during the ICT4153 Mobile Application Development course.

---

## 📂 Projects

| Project | Description | Key Concepts |
|---|---|---|
| `animated_startup_app` | Animated splash & startup screen | AnimationController, Tween, FadeTransition, RotationTransition |
| `dog_management` | Dog CRUD app with SQLite | sqflite, Clean Architecture, CRUD operations |
| `exam_test` | Student Manager exam practice app | sqflite, StatefulWidget, ListView, AlertDialog |
| `ui_test_app` | Multi-screen UI layout demo | Navigator, GridView, Stack, ListView.builder |

---

## 🛠️ Tech Stack
- **Framework:** Flutter (Dart)
- **Database:** SQLite via `sqflite` package
- **State Management:** setState
- **Architecture:** Clean Architecture (dog_management)

---

## 🚀 Getting Started

```bash
# Navigate to any project folder
cd exam_test

# Install dependencies
flutter pub get

# Run on Android emulator
flutter run
```
