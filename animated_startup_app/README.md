# Animated Startup App

A Flutter animation demo app built for ICT4153 Practical 08.

## Features
- Animated logo with fade transition
- Bouncing container animation
- Rotating container with continuous spin
- Uses AnimationController and Tween

## Concepts Covered
- `AnimationController` with `vsync`
- `Tween<double>` for value interpolation
- `FadeTransition`, `RotationTransition`
- `SingleTickerProviderStateMixin`

## Run
```bash
flutter pub get
flutter run
```
