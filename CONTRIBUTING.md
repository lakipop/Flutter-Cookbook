# Contributing

This is a university coursework repository for ICT4153.

## Project Structure
Each subdirectory is an independent Flutter project.

## Setup
1. Install Flutter SDK
2. Install Android Studio + emulator
3. cd into any project folder
4. Run: flutter pub get
5. Run: flutter run

## Code Style
- Follow Dart/Flutter naming conventions
- Use const constructors where possible
- Keep widgets small and focused
- Always call setState() to update UI state
